O que é a computação?

A base de tudo que você usa no dia a dia — do celular ao servidor na nuvem.

Hardware vs Software

Hardware é tudo que você pode tocar: processador, memória RAM, SSD. Software são os programas que rodam nesse hardware — do sistema operacional ao app de fotos.

FUNDAMENTOS

Como o Processador Funciona

O CPU executa bilhões de operações por segundo, seguindo um ciclo: Buscar → Decodificar → Executar.

ARQUITETURA

Memória e Armazenamento

RAM é rápida e temporária. SSD é persistente e mais lento. Cache é minúscula e ultra-rápida.

Bubble Sort

O(n²)

Compara pares adjacentes e os troca até a lista estar ordenada. Simples mas lento para listas grandes.

def bubble_sort(lista):
    n = len(lista)
    for i in range(n):
        for j in range(n - i - 1):
            if lista[j] > lista[j+1]:
                lista[j], lista[j+1] = \
                lista[j+1], lista[j]
    return lista

Busca Binária

O(log n)

Divide a lista ao meio repetidamente para encontrar o elemento. Muito mais eficiente que busca linear.

def busca_binaria(lista, alvo):
    esq, dir = 0, len(lista) - 1
    while esq <= dir:
        meio = (esq + dir) // 2
        if lista[meio] == alvo:
            return meio
        elif lista[meio] < alvo:
            esq = meio + 1
        else:
            dir = meio - 1
    return -1

Fibonacci

Recursão

Sequência onde cada número é a soma dos dois anteriores: 0, 1, 1, 2, 3, 5, 8, 13...

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + \
           fibonacci(n-2)

# Exemplo de uso
for i in range(8):
    print(fibonacci(i), end=" ")
